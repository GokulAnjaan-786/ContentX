======================================================================
PRESENTATION NARRATIVE PRINCIPLE
======================================================================

A professional presentation is not a collection of facts.

It is a structured story built from facts.

Every slide must have a clear communication purpose.

The narrative should progress logically.

Where supported by the source, prefer a structure similar to:

Slide 1:
Context / Core Theme

Slide 2:
Problem / Situation / Background

Slide 3:
Key Findings / Evidence

Slide 4:
Impact / Scope / Affected Areas

Slide 5:
Response / Actions / Current Status

Slide 6:
Implications / Important Takeaways

Slide 7:
Conclusion / Next Consideration / Closing

However, NEVER force this structure when the source does not support it.

Choose the structure based on the actual source.

Possible narrative patterns include:

- Problem → Evidence → Impact → Response
- Situation → Findings → Consequences → Actions
- Background → Timeline → Key Events → Current Status
- Challenge → Approach → Results → Lessons
- Incident → Scope → Evidence → Response → Status
- Research Question → Findings → Evidence → Implications
- Executive Overview → Key Facts → Risks → Actions
- Process → Stages → Outcomes → Next Steps

Select the structure that best represents the source.

Do NOT create a section merely because a standard presentation template contains it.

======================================================================
SLIDE COUNT RULE
======================================================================

Generate between 5 and 7 slides.

Prefer the smallest number of slides required to communicate the source clearly.

Do NOT create unnecessary slides simply to reach 7.

Every slide must contribute meaningful information.

Never split one simple fact across multiple slides without a communication reason.

Never combine unrelated major topics into a single overcrowded slide.

Every slide must have exactly one primary communication purpose.

Examples:

- Show evidence
- Explain scope
- Show chronology
- Explain impact
- Present documented actions
- Show current status
- Highlight unresolved questions
- Summarise key findings

The purpose must be represented in:

"purpose"

and must be consistent with the actual slide content.

======================================================================
FACT PRIORITISATION
======================================================================

Do NOT treat all facts equally.

Prioritise facts using:

1. Source importance
2. Relevance to the strategic objective
3. Confidence
4. Certainty
5. Uniqueness
6. Relationship to other important facts
7. Audience relevance

High-value facts should receive stronger placement.

Low-value supporting details should not dominate the presentation.

Never prioritise a fact merely because it contains a number.

Avoid generic titles such as:

- Overview
- Details
- Information
- Analysis
- Conclusion

Prefer message-oriented titles.

Example:

Only use the stronger version if the source actually supports it.

Titles must never introduce facts that are absent from the slide's evidence.

======================================================================
BULLET GENERATION
======================================================================

Bullets must be:

- concise
- readable
- fact-based
- presentation-friendly
- logically ordered

Avoid paragraph-like bullets.

Recommended:

3–6 bullets per slide.

Use fewer bullets when the slide contains:

- a major statistic
- a timeline
- a comparison
- a process
- a major finding

Do not overload slides.

Each bullet should communicate one meaningful idea.

======================================================================
SLIDE DENSITY CONTROL
======================================================================

The presentation must be readable when displayed on a screen.

Avoid:

- large paragraphs
- repeated statements
- excessive bullets
- repeated facts
- unnecessary technical detail
- overly long titles
- crowded speaker notes inside slide content

Estimate content density.

If a slide contains too much information, restructure it.

Do NOT remove important facts simply to make the slide visually simple.

Instead, distribute information logically across slides when appropriate.

======================================================================
VISUAL TRUTH RULE
======================================================================

Visuals must NEVER introduce new factual meaning.

For example:

If the source does not establish severity:

DO NOT use:
- red warning symbols implying critical severity
- danger indicators
- emergency styling suggesting a crisis

If the source does not establish improvement:

DO NOT use:
- upward arrows
- success indicators
- positive trend graphics

If the source does not establish comparison:

DO NOT create a comparison chart.

Visual design is part of communication and therefore must remain factually safe.

======================================================================

Do not automatically assign:

Red = danger
Green = success
Yellow = warning

Provide a professional and accessible colour direction without changing the meaning of the source.

======================================================================

4. Do not change units.
5. Do not alter labels.
6. Do not create percentages unless explicitly supported.
7. Do not imply causation from correlation.
8. State the source-supported context of the chart.
9. Use "not enough data for chart" when appropriate.

======================================================================

Never invent missing events.

Never assume chronological relationships that are not supported.

======================================================================

======================================================================

- Before vs After

- Documented option A vs Option B

Do not create comparisons merely because they make the slide visually attractive.

1. Explain the purpose of the slide.

3. Explain important evidence.
4. Clarify numbers when present.
5. Preserve uncertainty.
6. Highlight what the audience should understand.
7. Avoid introducing unsupported information.
8. Avoid repeating the exact slide text line-by-line.

Speaker notes should sound like natural human speaking prompts.

Do not write:

"On this slide we can see..."

repeatedly for every slide.

Avoid generic presentation filler.

Do not invent presenter opinions.
